# Mi plan de hipertrofia

App web de un solo archivo (`index.html`): plan de 52 semanas en fases (adaptación, base, volumen, fuerza, descargas y evaluación), checklist diario de ejercicios y series, tablero anual de cumplimiento, dieta y alarmas. No necesita compilar ni instalar nada.

## Desplegar en GitHub Pages

1. Crea un repositorio nuevo en GitHub y sube `index.html` y `README.md` a la rama `main`.
2. Ve a **Settings → Pages**.
3. En **Source** elige **Deploy from a branch**, rama `main`, carpeta `/ (root)`, y guarda.
4. En 1 o 2 minutos tendrás la app en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Uso en el celular

- Abre el enlace y usa "Agregar a pantalla de inicio".
- En **Alarmas**, toca "Activar notificaciones" y "Mantener pantalla encendida".
- Los datos se guardan en el navegador de cada dispositivo.

## Limitación importante

Las alarmas de una página web solo suenan con la app abierta (pestaña en primer plano). Si cierras el navegador o se bloquea el teléfono, pueden no sonar. Para alarmas garantizadas, usa también la app Reloj del teléfono con los mismos horarios.
